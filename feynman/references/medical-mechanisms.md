# 医学解剖与机理图规范

用于解剖定位、免疫机制、信号转导、病理过程、药理机制和分子相互作用。目标是让结构、方向和作用关系可核查，而不是把概念画得热闹。

## 先判断图的类型

| 用户问题 | 图的类型 | 首选资产或画法 |
|---|---|---|
| 器官在哪里、淋巴如何回流 | 解剖定位图 | `assets/medical/openstax/lymphatic-system-anatomy.jpg` |
| 先天免疫与适应性免疫由谁连接 | 免疫系统总览 | `assets/medical/reactome/immune-system-overview.png` |
| TLR、补体、炎症小体、中性粒细胞如何作用 | 先天免疫机制图 | `assets/medical/reactome/innate-immune-system.png` |
| BCR、TCR、MHC、抗体成熟如何发生 | 适应性免疫机制图 | `assets/medical/reactome/adaptive-immune-system.png` |
| 只有一个局部因果链且现有图过密 | 自制局部机制图 | 按本文的对象、分区和连线规则绘制 |
| 只问分类、定义或层级 | 概念图或思维导图 | 不冒充解剖图或通路图 |

已有授权资产能准确覆盖问题时，直接展示资产并解释，不重新手绘。需要补充时，优先裁切局部、添加编号或箭头说明；若修改原图，必须另存为衍生文件并保留署名与修改说明。

## 精准性底线

1. **分区准确**：按需画出细胞外空间、质膜、细胞质、细胞器、细胞核、组织或器官。箭头不能跨区却假装同一尺度。
2. **对象准确**：写具体细胞类型、受体、配体、复合物、基因、离子或代谢物。禁止只用“信号”“因子”“细胞”代替已知名称。
3. **方向准确**：每条关键连线都要有动作语义。普通箭头表示促进、流向、转位或转化；平头线表示抑制；虚线表示间接、易位或证据较弱的联系。
4. **定位准确**：受体画在膜上，转录因子进入细胞核，分泌蛋白位于细胞外，膜复合物不能漂在细胞质中。
5. **时间准确**：涉及先后顺序时，用编号、分镜或时间轴；不要用空间并排暗示严格的时间顺序。
6. **证据准确**：教材确定机制、数据库注释和推测模型分开标注。无法确认的关系写“机制未确认”，不能补一条看似顺滑的箭头。
7. **来源准确**：自制图在图注列出教材、综述、数据库或用户提供的资料；Reactome 图保留稳定标识符。

## 一张合格机制图的最小信息

```text
对象：谁作用于谁
分区：发生在膜外、膜上、胞质、细胞器、核内，还是器官之间
边：激活 / 抑制 / 结合 / 转位 / 催化 / 分泌 / 降解
顺序：起始刺激 → 中间节点 → 效应 → 表型
来源：数据库 ID、教材图号或引用
```

分子很多时只保留当前理解断点所需的主链，把旁支移到图注或下一步延伸。不能为了显得完整而把所有通路塞进一张图。

## 解剖图规则

- 先回答位置、毗邻、引流方向和分区，再谈功能。
- 器官轮廓、相对位置和连接关系必须来自可信解剖资料。
- 不用圆形、矩形或任意色块代替真实器官形状。
- 不把示意图当作影像学、组织学或病理切片。
- 需要比较成人、儿童或病理状态时，分别说明状态与来源。

人体免疫器官入门优先使用 OpenStax 解剖图。它适合说明胸腺、脾、骨髓、淋巴管和淋巴结，但不能单独证明细胞内的信号机制；继续讲细胞机制时切换到 Reactome 图。

## 通路图规则

### Reactome 资产

先列出图中的起始刺激、膜受体、胞内适配蛋白、关键激酶或转录因子、最终效应，再用中文解释英文标签。不要把 Reactome 的数据库注释改写成未经来源支持的新通路。

- `R-HSA-168256`：免疫系统总览；
- `R-HSA-168249`：先天免疫；
- `R-HSA-1280218`：适应性免疫。

Reactome 图像采用 CC BY 4.0。默认展示兼容性更好的 PNG；需要放大、打印或继续编辑时使用同名 SVG。展示或复制时必须保留 `assets/medical/ATTRIBUTION.md` 中的署名、许可链接和栅格化说明。

### 自制局部机制图

- 主链最多保留 5–7 个关键节点；更长的链拆成“识别—传导—效应”小面板。
- 每个节点使用可辨认的医学对象，不用无语义圆点。
- 同一张图只表达一个尺度。器官级解剖和分子级磷酸化不得混在同一空间尺度里。
- 只用颜色辅助分组，同时使用标签、线型和位置编码。
- 图后只追问一个理解性问题，例如“哪一步被阻断后，哪个下游效应最先消失？”

## 借鉴 BioGDP 的构图语言

学习其共性设计原则：对象风格一致、区室边界明确、激活链连续、标签紧邻对象、整体留白充足、图例不重复、箭头含义稳定。不得复制其图标、模板或原图来规避授权；要使用开放许可资产或自行绘制。

## 典型错误

| 错误 | 为什么误导 | 修正 |
|---|---|---|
| 用一个圆点代表淋巴结或脾 | 抹掉器官形状、位置和毗邻 | 使用解剖资产或明确写“非解剖示意” |
| 只画一条无标签箭头 | 无法区分激活、抑制、转位和流向 | 在边上写动作 |
| 把 MHC、TCR、CD 分子画在随机位置 | 破坏膜受体与细胞间界面的关系 | 按膜、胞质和细胞间接触面重画 |
| 把思维导图当机制图 | 从属关系不能代替因果与反馈 | 改用带动作标签的通路图 |
| 把推断关系画成确定事实 | 伪造医学证据 | 标“推测/争议/未确认” |

## 安全边界

这些图像只用于基础概念学习，不用于个人诊断、处方、剂量或急救决策。病理、药理和临床内容应优先核对当前教材、指南或权威数据库，并写出来源与检索日期。
