# 思维导图规范

当用户需要整理概念层级、比较多个子主题或形成会话后的知识地图时，使用 `../scripts/render_mindmap.py`。

## 输入格式

使用嵌套 Markdown 列表。第一条项目是中心主题：

```markdown
- 免疫系统
  - 中枢免疫器官
    - 骨髓
      - B 细胞成熟
    - 胸腺
      - T 细胞成熟
  - 外周免疫器官
    - 淋巴结
    - 脾
    - 黏膜相关淋巴组织
```

## 结构约束

- 中心主题只能有一个；
- 建议 4–7 个主分支，任何节点最多 7 个子节点；
- 最多四层，超过时拆分主题；
- 每个节点使用一个短概念，不写成完整段落；
- 如果两个概念之间不是从属关系，而是一条因果或作用关系，改用机制图或带标签的流程图；
- 导图根据用户已经讲过的内容生成，不擅自扩展成整章知识清单。

## 基础概念图优先模板

单个基础概念默认只画四个主分支：

```markdown
- 核心概念
  - 是什么
    - 核心对象
    - 一句话定义
  - 为什么
    - 核心机制
    - 因果关系
  - 条件与边界
    - 成立前提
    - 容易失效的地方
  - 易混与反例
    - 最接近的概念
    - 一个反例
```

使用要求：

- 四个主分支顺序固定，便于跨主题复习和比较；
- 每个主分支下只放 1–3 个关键词；
- 基础概念图不再继续嵌套更深的细节；
- 复杂器官系统、疾病分类等知识地图可以使用更多主分支，但仍遵守总深度限制；
- 用户尚未讲到的分支不要擅自补满，可留作下一轮追问。

## 视觉规则

- 一级分支各有固定颜色，后代继承同一颜色；
- 靠近中心的主干线更粗，向外逐级变细；
- 中心节点最大，一级主题次之，叶子节点最小；
- 同一分支颜色一致，但不能只依赖颜色区分；
- 线条使用柔和曲线，避免大量直角折线和交叉；
- 不使用装饰性图标堆叠，不用图片挤占关键词空间；
- 自动布局必须检查节点重叠、长标签换行和边缘裁切。

## 学习用法

先让用户凭记忆讲出或画出结构，再生成导图用于对比。不要一上来就把完整导图交给用户。

生成导图后只做一件事：

1. 请用户补上一个缺失分支；或
2. 请用户解释两个分支为什么并列/从属；或
3. 隐藏一个节点，让用户凭记忆恢复。

## 调用

```powershell
& <Python解释器> scripts/render_mindmap.py outline.md `
  --out-dir mindmap-output --theme dark
```

输出：

```text
mindmap.svg
mindmap.html
mindmap.png
mindmap.mmd
```

`mindmap.mmd` 是可交给支持 Mermaid 的宿主渲染的回退格式。Markmap 可作为可选交互形式，但默认本地 SVG/PNG 不依赖 CDN 或外部服务。

## 设计与研究依据

- [Mermaid Mindmap](https://mermaid.ai/open-source/syntax/mindmap.html)：采用缩进式层级，并输出兼容的 `mindmap.mmd`；
- [Markmap](https://markmap.js.org/docs/markmap)：采用 Markdown 大纲作为自然输入；
- [Graphviz dot](https://graphviz.org/docs/layouts/dot/)：借鉴分层布局和减少连线交叉的规则；
- [医学教育思维导图研究](https://www.facs.org/for-medical-professionals/news-publications/journals/rise/articles/cognitive/)：限制主分支数量、关键词长度和层级深度，以降低认知负荷。
