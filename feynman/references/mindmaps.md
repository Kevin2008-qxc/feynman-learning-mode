# 思维导图规范

当用户需要整理概念层级、比较多个子主题或形成会话后的知识地图时，使用 `../scripts/render_mindmap.py`。

## 输入格式

使用嵌套 Markdown 列表。第一条项目是中心主题：

```markdown
- 免疫系统
  - 中枢免疫器官
    - 骨髓
      - B 细胞成熟
    - 胸腺
      - T 细胞成熟
  - 外周免疫器官
    - 淋巴结
    - 脾
    - 黏膜相关淋巴组织
```

## 结构约束

- 中心主题只能有一个；
- 建议 4–7 个主分支，任何节点最多 7 个子节点；
- 最多四层，超过时拆分主题；
- 每个节点使用一个短概念，不写成完整段落；
- 如果两个概念之间不是从属关系，而是一条因果或作用关系，改用机制图或带标签的流程图；
- 导图根据用户已经讲过的内容生成，不擅自扩展成整章知识清单。

## 视觉规则

- 一级分支各有固定颜色，后代继承同一颜色；
- 靠近中心的主干线更粗，向外逐级变细；
- 中心节点最大，一级主题次之，叶子节点最小；
- 同一分支颜色一致，但不能只依赖颜色区分；
- 线条使用柔和曲线，避免大量直角折线和交叉；
- 不使用装饰性图标堆叠，不用图片挤占关键词空间；
- 自动布局必须检查节点重叠、长标签换行和边缘裁切。

## 学习用法

先让用户凭记忆讲出或画出结构，再生成导图用于对比。不要一上来就把完整导图交给用户。

生成导图后只做一件事：

1. 请用户补上一个缺失分支；或
2. 请用户解释两个分支为什么并列/从属；或
3. 隐藏一个节点，让用户凭记忆恢复。

## 调用

```powershell
& <Python解释器> scripts/render_mindmap.py outline.md `
  --out-dir mindmap-output --theme dark
```

输出：

```text
mindmap.svg
mindmap.html
mindmap.png
mindmap.mmd
```

`mindmap.mmd` 是可交给支持 Mermaid 的宿主渲染的回退格式。Markmap 可作为可选交互形式，但默认本地 SVG/PNG 不依赖 CDN 或外部服务。

## 设计与研究依据

- Mermaid 的缩进式 Mindmap 语法与 `mindmap.mmd` 兼容；
- Markmap 证明 Markdown 大纲可以自然映射为可折叠知识树；
- Graphviz 的分层布局用于约束层距、减少交叉和自动计算节点位置；
- 医学教育研究建议限制主分支数量、关键词长度和层级深度，以降低认知负荷。
